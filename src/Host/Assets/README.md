# UI assets

`app.ico`, `avatar.png`, and `chiptune.wav` are original assets created for
the open-source build. They are distributed under the project's MIT license.

The build scripts require the files:

- `app.ico` is used as the executable and window icon.
- `avatar.png` is embedded as the title-bar icon in the WinForms UI.
- `chiptune.wav` is an original 16kHz, 8-bit mono loop embedded in the single-file build after gzip compression.

You can replace them with your own artwork or music, but make sure you have
permission to redistribute the replacement assets.
