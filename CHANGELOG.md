# Changelog

## 2.0.0 - 2026-10-22

- Win98/keygen-style GUI with original CRT icon and mono terminal log
- Original 8-bit keygen-style music, enabled by default and replaceable via the `SOUND` button
- HMCL 3.17 classfile support, including download-page and mod-download-page region calls
- PCL2 / PCL2 CE / HMCL detection, apply, restore, side-by-side output, and backup management
- `--no-backup` mode with explicit warnings and disabled restore
- Single-file EXE with gzip-compressed audio and Mono.Cecil resources
- Open-source packaging with attribution, third-party notices, and focused tests
